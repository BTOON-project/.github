# Getting help

- **Questions, ideas and use cases:** [GitHub Discussions](https://github.com/BTOON-project/btoon-core/discussions) on btoon-core. That's also the place to say how you use BTOON and what you'd need from it.
- **Bugs:** open an issue in the repository of the library concerned, with the library version and a minimal reproduction.
- **Changes to the format:** open an issue in [btoon-core](https://github.com/BTOON-project/btoon-core/issues/new/choose) with the "Spec change" template.
- **Security problems:** report them privately, as [SECURITY.md](SECURITY.md) describes.

Documentation:
- [btoon.net/docs](https://btoon.net/docs), with an in-browser playground;
- [the specification](https://github.com/BTOON-project/btoon-core/blob/main/docs/SPEC.md);
- each library's README.
